## 读之前要知道的

1. **每篇文章开头都挂了「数据底座」**：文中所有百分比、密度、极差、引语出处，均可溯源与复算。
2. **观点有清晰的边界**：凡属假说或经验归纳的，明确区分证据级别；不把个案特征包装成普遍规律。
3. **配图兼顾矢量与分享**：
   - 思想家网络图采用纯 **SVG 矢量格式**，无限缩放无模糊；
   - 经济学人风方法论卡片提供 **交互式 HTML 视图**（正文可点击题图直接全屏查看），同时随仓附带高清 PNG 便于社交媒体传播；
   - 全部配图均脱敏去除了私有知识库痕迹，署名 `@zhangxunnj`。

## 命名

「白石溪」取自山水里一条不起眼的名字：石头是白的，水是真的，不长高东西，也不装。写作用来记这条路。
