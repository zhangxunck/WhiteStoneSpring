# 白石溪 · White Stone Spring

> 一条持续调查「语言、写作与思想」的溪。

白石溪是一个公开的文章仓。这里放的是我自己写的长文——关于中文怎么写、为什么这么写、以及 AI 时代它还能不能保持干净。每篇都建立在可复算的数据上，不留「我觉得」，只留「语料库里的数字是这么说的」。

## 读之前要知道的

- **每篇文章开头都挂了「数据底座」**。文中所有百分比、密度、极差，都能从对应语料库复算出来。复算脚本（`zh_style_stats.py`、`zh_genre_stats.py`）和原始语料在作者的私有库中，本文只呈现实测结果。
- **观点有边界**。凡「通说」与「实测」打架的地方，文章会把两边都摆出来，不会假装已证实的因果。
- **配图是经济学人风方法论卡**，随文放 `assets/` 下。

## 命名

「白石溪」取自山水里一条不起眼的名字：石头是白的，水是真的，不长高东西，也不装。写作用来记这条路。

## 约定

- 仓库名 `WhiteStoneSpring`（ASCII，便于 GitHub 检索与链接）
- 文章平铺在 `articles/`（Jekyll collection），配图统一放 `assets/`
- 图片统一放 `assets/`，正文用相对路径 `../assets/xxx.png` 引用
- 发新版直接 push `main`，GitHub Pages 可挂起（待启用）
